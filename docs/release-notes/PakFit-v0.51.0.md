# PakFit v0.51.0 Release Notes

- Release evidence version 0.51.0 build 51.
- Adds diabetes medication safety mode across Android and iOS recommendation engines.
- Pauses aggressive calorie deficits or surpluses when diabetes medication caution is selected.
- Switches diabetes medication workout output to clinician-reviewed moderate movement instead of fat-loss or muscle-gain labels.
- Adds glucose-aware Pakistani meal guidance for consistent roti, rice, fruit, dates, desserts, and sweet-drink carbohydrate portions.
- Adds Ramadan-specific diabetes medication timing guidance for suhoor, iftar, hydration, glucose checks, medication timing, and avoiding hard fasted training until clinician review.
- Adds Android unit, Swift smoke, Swift XCTest source, CI, release validation, and release evidence checks for the new safety gate.
