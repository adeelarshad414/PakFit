# PakFit v0.48.0 Release Notes

PakFit version 0.48.0 build 48 upgrades pregnancy safety from a warning-only behavior to a plan-modifying safety state.

## Added

- Android and iOS pregnancy safety behavior that pauses ordinary fat-loss calorie deficits.
- Clinician-reviewed pregnancy nutrition guidance with steady meals and safe hydration language.
- Clinician-cleared gentle movement plan for pregnancy caution.
- Stop-warning symptom guidance for pregnancy movement.
- Android unit coverage plus iOS smoke/XCTest coverage for pregnancy plan safety.
- Pregnancy plan safety gate, documentation, CI wiring, store copy, and release evidence reporting.

## Boundary

Pregnancy support is safety-oriented education only. PakFit does not prescribe prenatal nutrition, prescribe exercise, manage complications, diagnose pregnancy risk, or replace obstetric care.
