# App Identity Metadata Gate

## Objective

Make PakFit's Android and iOS release-channel identity explicit and testable so package IDs, bundle IDs, display names, and target family metadata cannot drift silently before APK/AAB or iOS release evidence is accepted.

## Requirements

- Android namespace must remain `com.pakfit.app`.
- Android application ID must remain `com.pakfit.app`.
- Android display name must remain `PakFit`.
- Android manifest must use `@string/app_name` as the application label.
- iOS bundle identifier must remain `com.pakfit.ios`.
- iOS display name must remain `PakFit`.
- iOS target device family must include iPhone and iPad.
- iOS supported platforms must remain `iphoneos iphonesimulator`.
- Mac Catalyst must stay disabled until a reviewed desktop UI/spec exists.
- CI and local release validation must run the same app identity metadata gate.
- Release evidence must record Android/iOS identity metadata and gate status.
- Android and iOS version metadata must be bumped for release artifacts generated by this packaging slice.

## Boundaries

- This gate does not reserve store listing names or prove Play Console/App Store Connect ownership.
- Future bundle ID migration, white-label build, app rename, Mac Catalyst build, or alternate distribution channel requires a spec update, store/privacy review, and new release evidence.
- This gate must not require signing secrets, Play Console access, App Store Connect access, backend services, analytics keys, or cloud health data.

## Acceptance Criteria

### Scenario: Android app identity stays stable

Given the release validation command runs
When Android Gradle, manifest, and string resources are inspected
Then Android namespace and application ID remain `com.pakfit.app`
And the user-facing display name remains `PakFit`.

### Scenario: iOS app identity stays stable

Given the release validation command runs
When iOS Xcode project metadata is inspected
Then the bundle identifier remains `com.pakfit.ios`
And the display name remains `PakFit`
And iPhone/iPad are the supported app families.
