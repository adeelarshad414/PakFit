# Spec 033 - Gradle Wrapper Reproducibility

## Objective

Improve PakFit's build reproducibility by checking in a pinned Gradle Wrapper, verifying the Gradle distribution checksum, and enforcing wrapper integrity during release validation and CI.

## Functional Requirements

- The repository must include `gradlew`, `gradlew.bat`, `gradle/wrapper/gradle-wrapper.jar`, and `gradle/wrapper/gradle-wrapper.properties`.
- The Gradle Wrapper must pin Gradle `8.14.5`.
- `gradle-wrapper.properties` must include the official Gradle `8.14.5` binary distribution SHA-256.
- Local release validation must fail if wrapper files are missing, `gradlew` is not executable, Gradle version is not pinned, the distribution SHA is missing/changed, or the wrapper JAR checksum changes without an intentional update.
- Local scripts should prefer `./gradlew` when available.
- CI should run Android tasks through `./gradlew`.
- Release evidence must record wrapper distribution URL, distribution SHA-256, wrapper JAR SHA-256, and wrapper script checksums.
- Android and iOS version metadata must be bumped for the release artifacts generated by this reproducibility slice.

## Non-Functional Requirements

- Wrapper integrity checks must not require signing secrets, backend services, analytics keys, Play Console access, or cloud health data.
- The checked-in wrapper should reduce dependence on machine-installed Gradle versions.
- The wrapper distribution checksum must come from Gradle's official distribution checksum endpoint.

## Acceptance Evidence

- `bash scripts/validate-release.sh` checks the Gradle Wrapper before Android build tasks.
- `.github/workflows/pakfit-ci.yml` runs Android tasks through `./gradlew`.
- `scripts/generate-release-report.sh` records wrapper reproducibility evidence.
- `bash scripts/validate-release.sh` passes locally.

## Release Boundary

This slice proves Gradle build tool reproducibility. It does not remove the external need for Android upload-key signing, Play Console validation, live vulnerability advisory scanning, or full Xcode/iOS signing.
