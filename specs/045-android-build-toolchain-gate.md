# Android Build Toolchain Gate

## Objective

Remove the compileSdk 35 Android Gradle Plugin warning by upgrading PakFit to an AGP line that officially supports API 35 and proving the project does not hide unsupported compile SDK warnings.

## Requirements

- Android Gradle Plugin must be 8.6.0 or higher.
- Android Gradle Plugin 8.6.x is acceptable for the current API 35 slice because official release notes state AGP 8.6 supports API level 35.
- Gradle Wrapper must remain on the verified Gradle 8.14.5 distribution for this slice.
- `gradle.properties` must not contain `android.suppressUnsupportedCompileSdk`.
- Strict Gradle dependency verification metadata must be refreshed for any resolved AGP artifacts.
- CI and local release validation must run the same Android build toolchain gate.
- Release evidence must record Android Gradle Plugin version and build toolchain gate status.
- Android and iOS version metadata must be bumped for release artifacts generated by this toolchain-hardening slice.

## Boundaries

- This gate does not upgrade Kotlin, Compose Compiler, or Gradle Wrapper.
- This gate does not prove dependencies are free of vulnerabilities; live advisory scanning still requires a network-enabled scanner or hosted dependency review service.
- This gate must not require signing secrets, Play Console access, backend services, analytics keys, or cloud health data.

## Acceptance Criteria

### Scenario: AGP supports API 35

Given the release validation command runs
When Android build toolchain metadata is inspected
Then Android Gradle Plugin is at least 8.6.0
And Gradle Wrapper remains on the verified Gradle 8.14.5 distribution.

### Scenario: Unsupported compile SDK warnings are not hidden

Given the release validation command runs
When `gradle.properties` is inspected
Then `android.suppressUnsupportedCompileSdk` is absent.
