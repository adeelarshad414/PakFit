# Spec 031 - Android Backup Privacy Hardening

## Objective

Reduce accidental cloud/device-transfer exposure risk for PakFit's sensitive local health snapshot by disabling Android Auto Backup, excluding the snapshot preference from backup/data-extraction rules, and recording this posture in release validation evidence.

## Functional Requirements

- Android manifest must set `android:allowBackup="false"`.
- Android manifest must reference `@xml/backup_rules`.
- Android manifest must reference `@xml/data_extraction_rules`.
- `backup_rules.xml` must exclude `pakfit_local_snapshot.xml`.
- `data_extraction_rules.xml` must include both cloud-backup and device-transfer sections.
- `data_extraction_rules.xml` must exclude `pakfit_local_snapshot.xml` from cloud backup and device transfer.
- Local release validation must fail if Android backup privacy rules are missing or regressed.
- Release evidence report must state Android Auto Backup status, backup/data-extraction rule references, and sensitive snapshot exclusion status.
- Version metadata must be bumped for the release artifacts generated by this privacy hardening slice.

## Non-Functional Requirements

- The app remains offline-first with no backend, account, analytics, or cloud sync dependency.
- User-controlled plaintext export remains explicit and consent-gated.
- Android backup hardening must not remove the existing encrypted local snapshot save/restore flow.
- Backup privacy checks must run without Play Console, signing secrets, or cloud services.

## Acceptance Evidence

- `app/src/main/AndroidManifest.xml` disables Auto Backup and references backup/data-extraction rules.
- `app/src/main/res/xml/backup_rules.xml` excludes `pakfit_local_snapshot.xml`.
- `app/src/main/res/xml/data_extraction_rules.xml` excludes `pakfit_local_snapshot.xml` for cloud backup and device transfer.
- `scripts/validate-release.sh` includes an Android backup privacy gate.
- `scripts/generate-release-report.sh` records Android backup privacy status.
- `bash scripts/validate-release.sh` passes locally.

## Release Boundary

This slice prevents automatic Android backup/transfer of the sensitive local snapshot in this build. It does not replace the user-controlled export path, and it does not prove Play Store submission until upload signing and Play Console validation are complete.
