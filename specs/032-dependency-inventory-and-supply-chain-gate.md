# Spec 032 - Dependency Inventory and Supply Chain Gate

## Objective

Improve PakFit's release supply-chain posture by generating an offline dependency inventory, blocking dynamic or SNAPSHOT dependency declarations, and recording dependency evidence in release reports and CI artifacts.

## Functional Requirements

- Local validation must generate a dependency inventory before release evidence is finalized.
- Android dependency evidence must include declared dependencies and Gradle dependency trees for release, debug, and unit-test runtime classpaths.
- iOS dependency evidence must state Swift package dependency declarations. If none exist, the inventory must say so explicitly.
- Dynamic, `latest.*`, `+`, and `SNAPSHOT` dependency declarations must fail the dependency inventory gate.
- Release evidence must include dependency inventory report path and checksums.
- CI must generate and upload dependency inventory files with release evidence artifacts.
- Android and iOS version metadata must be bumped for the release artifacts generated by this supply-chain slice.

## Non-Functional Requirements

- The dependency inventory must work offline from already-resolved Gradle/Swift state.
- The gate must not require backend credentials, signing secrets, analytics keys, Play Console access, or cloud services.
- Public vulnerability advisory checks remain a future network-enabled scanner step.
- Dependency outputs must write to ignored release report folders by default.

## Acceptance Evidence

- `scripts/generate-dependency-inventory.sh` creates a Markdown report and dependency tree text files.
- `scripts/validate-release.sh` runs the dependency inventory gate.
- `scripts/generate-release-report.sh` includes dependency inventory checksums.
- `.github/workflows/pakfit-ci.yml` uploads dependency inventory files.
- `bash scripts/validate-release.sh` passes locally.

## Release Boundary

This slice proves dependency inventory and dynamic-version blocking. It does not prove current CVE/advisory status until a network-enabled vulnerability scanner or hosted dependency review service is configured.
